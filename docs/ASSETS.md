# 26. Prioridade de Produção

Não produzir todos os assets ao mesmo tempo.

Ordem sugerida:

1. plataforma simples;
2. coluna simples;
3. personagem placeholder;
4. asas;
5. animação básica;
6. assets do graybox;
7. assets da Região 1;
8. assets das outras regiões;
9. VFX;
10. assets de cutscene;
11. assets extras.

# 27. Regra de Reutilização

Sempre que possível, reutilizar assets.

Exemplos:

uma coluna pode gerar:

- coluna inteira;
- coluna quebrada;
- coluna pequena;
- coluna inclinada.

Uma nuvem base pode gerar:

- pequena;
- média;
- grande;
- escura;
- temporária.

Isso reduz muito o trabalho de modelagem.

# 28. Regra de Qualidade

Prioridade:

**consistência visual > quantidade de assets.**

É melhor possuir poucos modelos que combinem entre si do que muitos modelos com estilos completamente diferentes.

# 29. Assets Externos

Caso sejam utilizados assets externos, precisamos registrar:

- origem;
- autor;
- licença;
- link;
- modificações realizadas.

Nada deve ser colocado no projeto sem verificar licença.
